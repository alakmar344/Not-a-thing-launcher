## Highlights of v13

- Added the in-process `-1` **Essential Space** overlay (`LauncherOverlayManager`) with Daily Briefing, Hardware Switchboard, Scratchpad Note, Voice Memos, Focus Timer/Stopwatch, and Device Vitals.
- Expanded from 4 to 11 interactive in-process `NothingWidget` elements (`QuickTogglesWidget`, `FocusTimerWidget`, `EssentialNoteWidget`, `HabitMatrixWidget`, `VitalsWidget`, `CompassStepWidget`, `SmartFolderWidget`).
- Shipped offline `CommandEngine` search, `NothingSearchAlgorithm`, Grid ↔ List `DrawerHeader`, biometric `HiddenVaultSheet`, `LauncherEntryActivity` Setup Hub, 4 starter presets, `.nothing.json` backup/restore, 5 hardware accent palettes, `DOTS` icon style, ADW/Nova icon packs, `SpringAnimation` tactile feedback, and configurable home gestures.
