# Architecture

Not a Thing is a **design, telemetry, and productivity layer on top of stock AOSP Launcher3**, not a launcher written from scratch. Upstream Launcher3 (vendored unmodified under `third_party/aosp/launcher3`) owns the workspace database, drag & drop, folders, widget hosting, and loader lifecycle; this repo's product code lives under `app/src/main/java/com/nothinglauncher/` and resource overrides under `app/src/main/res/`.

For project directories and build tasks, see the [root README](../README.md#project-layout) and [`third_party/aosp/README.md`](../third_party/aosp/README.md). Archived pre-v11.0, v12, and v13 notes live under [`archive/`](archive/).

## 1. How the layer attaches to Launcher3

Launcher3 exposes explicit derivative extension points so Not a Thing avoids forking AOSP sources:

| Extension point | What Not a Thing does with it |
|---|---|
| `Launcher` activity subclass | [`NothingLauncher`](../app/src/main/java/com/nothinglauncher/home/NothingLauncher.kt) wires [`EssentialSpaceOverlay`](../app/src/main/java/com/nothinglauncher/space/EssentialSpaceOverlay.kt), backdrop & parallax/ripples, home gestures (`createTouchControllers()`), hardware `/` Search hotkey (`onKeyUp()`), long-press shortcuts (`getSupportedShortcuts()`), recent launch tracking (`startActivitySafely()`), label-free home visibility, `CustomizeSheet`, and phone / 6-column Bento first-run tiles |
| `LauncherOverlayManager` + `LauncherOverlayTouchProxy` | [`EssentialSpaceOverlay`](../app/src/main/java/com/nothinglauncher/space/EssentialSpaceOverlay.kt) implements an in-process `-1` overlay returned by `getDefaultOverlay()` and adapts cleanly to a 2-column Bento layout (`layout-w600dp/essential_space_overlay.xml`) |
| `AllAppsContainerView` / Search layout overrides | `res/layout/all_apps.xml` swaps in [`NothingAllAppsContainerView`](../app/src/main/java/com/nothinglauncher/drawer/NothingAllAppsContainerView.kt); `res/layout/nt_drawer_header.xml` and [`DrawerSearchBox`](../app/src/main/java/com/nothinglauncher/drawer/DrawerSearchBox.kt) install [`NothingSearchAlgorithm`](../app/src/main/java/com/nothinglauncher/drawer/NothingSearchAlgorithm.kt) + [`NothingSearchAdapterProvider`](../app/src/main/java/com/nothinglauncher/drawer/NothingSearchAdapterProvider.kt) |
| `R.string.launcher_activity_logic_class` (`ResourceBasedOverride`) | [`NothingIconLogic`](../app/src/main/java/com/nothinglauncher/icons/NothingIconLogic.kt) intercepts icon rendering and per-app custom labels across Home and All Apps |
| `SettingsActivity` replacement (`tools:node="replace"`) | [`NothingSettingsActivity`](../app/src/main/java/com/nothinglauncher/settings/NothingSettingsActivity.kt) serves `APPLICATION_PREFERENCES` with 2-column Bento layout + live Studio preview on wide screens while linking to stock Launcher3 settings |
| Resource overriding (`res.srcDirs`) | `app/src/main/res-launcher3-theme` (generated by `tools/gen_nothing_theme.py`) replaces wallpaper-derived Material You tokens with Nothing monochrome + red tokens |
| `CustomWidgetPlugin` / `R.array.custom_widget_providers` | Registers all 12 [`NothingWidget`](../app/src/main/java/com/nothinglauncher/widgets/NothingWidget.kt) elements directly inside Launcher3's stock widget picker with Android S+ previews and descriptions |
| `src_ui_overrides` (`launcher3/src/overrides/java`) | `PluginManagerWrapper` wires custom widgets into Launcher3's plugin loading |

## 2. Big-Screen Adaptive Architecture & Glyph Desk HUD

- **Responsive Breakpoints ([`BigScreenUi`](../app/src/main/java/com/nothinglauncher/BigScreenUi.kt)):** Centralizes `w600dp`/`w680dp`/`w900dp` layout decisions (`isLargeScreen`, `isUltraWide`, `drawerListColumns` 1/2/3, `searchCommandColumns` 1/2, `sheetWindowWidthPx` capped at `540dp` on tablets, and `applyMaxWidth`).
- **4-Stage Glyph Desk HUD ([`DeskHudActivity`](../app/src/main/java/com/nothinglauncher/DeskHudActivity.kt) + [`GlyphMatrixCanvasView`](../app/src/main/java/com/nothinglauncher/GlyphMatrixCanvasView.kt)):** Edge-to-edge stand-by console (`Theme.NothingLauncher.Desk`) with `layout/activity_desk_hud.xml` (phone) and `layout-w600dp/activity_desk_hud.xml` (2-column tablet cockpit). Switches live and persists across rebirth between `COCKPIT`, `CLOCK`, `FOCUS`, and `GLYPH` stages via pill bar or hardware keys (`1–4`, `Tab`/`M`, `C`, `F`, `H`, `Space`), renders concentric C-arc LEDs reactive to media playback and Focus Timer progress, supports 1-tap Habit check-ins, and includes optional OLED burn-in pixel shift (`deskBurnInShift`).
- **`NothingLauncher`, Gestures & `-1` Essential Space:** On 6+ column workspaces, first-run `placeDefaultTiles()` populates a balanced 2×2 Bento grid (`ClockWidget` + `WeatherWidget` on row 0, `BatteryCalendarWidget` + `DeskBriefingWidget` on row 2). Swiping right opens `EssentialSpaceOverlay`, which on `w600dp`+ expands to a dual-column dashboard including the Habit Matrix check-in pegboard and a live Now Playing Media Deck.

## 3. Preferences, Repositories & Widget Surfaces

- [`NothingPrefs`](../app/src/main/java/com/nothinglauncher/NothingPrefs.kt) stores all configuration, notes, timer timestamps, habit dates, hidden package sets, custom app labels, recent component history, quick folder bindings, `deskMode`, and per-widget [`AccentTheme.WidgetSurface`](../app/src/main/java/com/nothinglauncher/AccentTheme.kt) overrides (`DEFAULT`, `DARK`, `PAPER`, `GLASS`), with an in-memory fallback for headless tests.
- [`SetupBackupManager`](../app/src/main/java/com/nothinglauncher/SetupBackupManager.kt) serializes/deserializes `.nothing.json` workspace setups (including `widgetSurfaces` and `deskMode`) via Storage Access Framework and provides 4 presets (`TELEMETRY`, `MONOLITH`, `COMMAND`, `STUDIO`). [`LauncherEntryActivity`](../app/src/main/java/com/nothinglauncher/LauncherEntryActivity.kt) renders presets as a 2-column Bento grid on tablets with active-preset highlighting.
- Shared zero-idle repositories synchronize Home widgets, Essential Space, and Desk HUD without background services: `WeatherRepository` (now including hourly precipitation probability & wind km/h), `MediaSessionRepository`, `HardwareControlRepository`, `FocusTimerRepository`, and `VoiceMemoRepository`.

## 4. Dot-Matrix Widgets (12 Elements)

All 12 widgets extend [`NothingWidget`](../app/src/main/java/com/nothinglauncher/widgets/NothingWidget.kt) under `app/src/main/java/com/nothinglauncher/widgets/` and are registered in append-only order in `R.array.custom_widget_providers` ([`nt_config.xml`](../app/src/main/res/values/nt_config.xml)):

| # | Class | Behaviour |
|---|---|---|
| 0 | `ClockWidget` | Digital (12/24h + seconds), `AnalogDotClockView`, `WordClockFormatter`, and World Clock (`worldClockZoneId`); surface-themed |
| 1 | `BatteryCalendarWidget` | Full-width `BatteryDotsView` + charging bolt, Calendar date link, and auto-hidden empty alarm row |
| 2 | `WeatherWidget` | Open-Meteo conditions with compact (`2×2`) vs wide (`4×2+`) 12h temperature sparkline, hourly rain baseline, & wind km/h |
| 3 | `MediaWidget` | Live track/artist, transport controls, output route (`BT`/`WIRED`/`SPEAKER`), and `MediaArtHalftone` |
| 4 | `QuickTogglesWidget` | Direct tiles for Torch, Focus Mode, Caffeine, and Ringer cycle |
| 5 | `FocusTimerWidget` | `DotRingGaugeView` Pomodoro timer & stopwatch synced with Essential Space & Desk HUD |
| 6 | `EssentialNoteWidget` | Always-visible scratchpad synced with Essential Space & Desk HUD |
| 7 | `HabitMatrixWidget` | 7×7 historical habit streak grid (`HabitPegboardView`) with 1-tap check-in (`isDoneToday`/`toggleToday`) |
| 8 | `VitalsWidget` | Storage + live RAM dot bars and optional daily `UsageStatsManager` screen time |
| 9 | `CompassStepWidget` | Hardware azimuth dot compass + step counter strictly gated on `onVisibilityAggregated` |
| 10 | `SmartFolderWidget` | Essential Stack supporting 1-app Max Icon mode or up to 4-app quick-launch stack |
| 11 | `DeskBriefingWidget` | Time-aware briefing, cached weather, calendar/alarm summary, live Focus Timer toggle pill, and 1-tap `DeskHudActivity` launch |

[`DateTimeWidgetProvider`](../app/src/main/java/com/nothinglauncher/widgets/DateTimeWidgetProvider.kt) remains registered as a lightweight `AppWidgetProvider` so Launcher3's `CustomWidgetManager` always binds the in-process elements above.

## 5. Command Search, Smart Drawer Categories & Hidden Vault

- [`CommandEngine`](../app/src/main/java/com/nothinglauncher/search/CommandEngine.kt) evaluates recursive-descent math + `%`, unit & temperature conversions, city timezone lookups, hex/named color inspection (`evalColor`), offline utilities (`uuid`, `dice`, `coin`, palette info via `evalUtility`), quick actions (`timer`, `note`, `preset`, toggles, `desk`), optional `READ_CONTACTS` filtering, web search, and acronym/fuzzy app matching.
- [`NothingAllAppsContainerView`](../app/src/main/java/com/nothinglauncher/drawer/NothingAllAppsContainerView.kt) supports `GRID` ↔ multi-column `LIST` ↔ smart `CATEGORIES` ([`AppCategorizer`](../app/src/main/java/com/nothinglauncher/drawer/AppCategorizer.kt) bucketing via `ApplicationInfo.category` + package fallbacks), renders 2-column Command Cards on wide screens via [`NothingSearchAdapterProvider`](../app/src/main/java/com/nothinglauncher/drawer/NothingSearchAdapterProvider.kt), attaches its adapter observer post-construction (`ensureObserverAttached()`), filters `HiddenVault` packages, and pairs with [`DrawerHeader`](../app/src/main/java/com/nothinglauncher/drawer/DrawerHeader.kt).

## 6. Visual Tiers, Tactile Physics, Icons & Accents

- [`VisualTier`](../app/src/main/java/com/nothinglauncher/perf/VisualTier.kt) classifies devices into `LITE` / `BALANCED` / `RICH` (with `ApplicationExitInfo` pressure fallback and trim eviction). `GlyphMatrixCanvasView`, `SecondsTickerView`, `MediaDotsView`, and `BatteryDotsView` gate animation strictly on visibility and `VisualTier.motionAllowed`.
- [`Tactile`](../app/src/main/java/com/nothinglauncher/Tactile.kt), [`TactileAudio`](../app/src/main/java/com/nothinglauncher/TactileAudio.kt), [`NothingIconLogic`](../app/src/main/java/com/nothinglauncher/icons/NothingIconLogic.kt), [`IconPackManager`](../app/src/main/java/com/nothinglauncher/icons/IconPackManager.kt), and [`AccentTheme`](../app/src/main/java/com/nothinglauncher/AccentTheme.kt) complete the tactile visual system.

## 7. Build Pipeline & R8 Reflection Contract

```
third_party/aosp/launcher3/   <- vendored, unmodified AOSP sources
         |
         v
   :launcher3, :iconloader, :animationlib   <- compiles AOSP sources + config & src_ui_overrides
         |
         v
       :app   <- com.nothinglauncher: v14 UI, Big-Screen Studio, Desk HUD, 12 widgets, overlay, search, vault, settings
```

All 12 `NothingWidget` subclasses in `R.array.custom_widget_providers`, `NothingIconLogic`, and `AppsSearchContainerLayout.mSearchBarController` are preserved through R8 via `app/proguard-rules.pro` and `launcher3/consumer-rules.pro`, verified after every `assembleRelease` by `tools/verify_release_reflection.py`.
