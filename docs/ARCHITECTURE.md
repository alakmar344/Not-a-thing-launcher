# Architecture

Not a Thing is a **design, telemetry, and productivity layer on top of stock AOSP Launcher3**, not a launcher written from scratch. Upstream Launcher3 (vendored unmodified under `third_party/aosp/launcher3`) owns the workspace database, drag & drop, folders, widget hosting, and loader lifecycle; this repo's product code lives under `app/src/main/java/com/nothinglauncher/` and resource overrides under `app/src/main/res/`.

For project directories and build tasks, see the [root README](../README.md#project-layout) and [`third_party/aosp/README.md`](../third_party/aosp/README.md). Archived pre-v11.0 and v12 architecture notes live under [`archive/`](archive/).

## 1. How the layer attaches to Launcher3

Launcher3 exposes explicit derivative extension points so Not a Thing avoids forking AOSP sources:

| Extension point | What Not a Thing does with it |
|---|---|
| `Launcher` activity subclass | [`NothingLauncher`](../app/src/main/java/com/nothinglauncher/home/NothingLauncher.kt) wires [`EssentialSpaceOverlay`](../app/src/main/java/com/nothinglauncher/space/EssentialSpaceOverlay.kt), backdrop & parallax/ripples, home gestures (`createTouchControllers()`), long-press shortcuts (`getSupportedShortcuts()`), recent launch tracking (`startActivitySafely()`), label-free home visibility, `CustomizeSheet`, and first-run tiles |
| `LauncherOverlayManager` + `LauncherOverlayTouchProxy` | [`EssentialSpaceOverlay`](../app/src/main/java/com/nothinglauncher/space/EssentialSpaceOverlay.kt) implements an in-process `-1` overlay returned by `getDefaultOverlay()` and dismissed via `onStateBack()` |
| `AllAppsContainerView` / Search layout overrides | `res/layout/all_apps.xml` swaps in [`NothingAllAppsContainerView`](../app/src/main/java/com/nothinglauncher/drawer/NothingAllAppsContainerView.kt); `res/layout/nt_drawer_header.xml` and [`DrawerSearchBox`](../app/src/main/java/com/nothinglauncher/drawer/DrawerSearchBox.kt) install [`NothingSearchAlgorithm`](../app/src/main/java/com/nothinglauncher/drawer/NothingSearchAlgorithm.kt) + [`NothingSearchAdapterProvider`](../app/src/main/java/com/nothinglauncher/drawer/NothingSearchAdapterProvider.kt) |
| `R.string.launcher_activity_logic_class` (`ResourceBasedOverride`) | [`NothingIconLogic`](../app/src/main/java/com/nothinglauncher/icons/NothingIconLogic.kt) intercepts icon rendering and per-app custom labels across Home and All Apps |
| `SettingsActivity` replacement (`tools:node="replace"`) | [`NothingSettingsActivity`](../app/src/main/java/com/nothinglauncher/settings/NothingSettingsActivity.kt) serves `APPLICATION_PREFERENCES` while still linking to stock Launcher3 settings ("Advanced home settings") |
| Resource overriding (`res.srcDirs`) | `app/src/main/res-launcher3-theme` (generated by `tools/gen_nothing_theme.py`) replaces wallpaper-derived Material You tokens with Nothing monochrome + red tokens |
| `CustomWidgetPlugin` / `R.array.custom_widget_providers` | Registers all 11 [`NothingWidget`](../app/src/main/java/com/nothinglauncher/widgets/NothingWidget.kt) elements directly inside Launcher3's stock widget picker with Android S+ previews and descriptions |
| `src_ui_overrides` (`launcher3/src/overrides/java`) | `PluginManagerWrapper` wires custom widgets into Launcher3's plugin loading |

## 2. `NothingLauncher`, Gestures & `-1` Essential Space

- **Living Backdrop ([`DotGridDrawable`](../app/src/main/java/com/nothinglauncher/DotGridDrawable.kt)):** Switches between Interactive Dot Grid, Solid Black/Bone, and Wallpaper. On Dots mode, `setParallax()` shifts the ambient light pool shader horizontally across workspace pages and vertically into All Apps, `triggerRipple()` animates an accent-tinted ring (`AccentTheme.accentColor`) on empty-space taps (`BALANCED`/`RICH`), and late-hour or Focus Mode attenuates ambient dot brightness (`nightDimDots`).
- **Home Gestures (`HomeGestureController`) & Screen Lock:** Overrides `createTouchControllers()` to recognize Swipe Down (ignoring vertically scrollable widgets), Double-Tap on empty space, and 2-finger Pinch-in, routing each to Notification Shade, Command Search, Essential Space, Customize Sheet, Hidden Vault, or biometric-preserving Screen Lock via [`NothingLockAccessibilityService`](../app/src/main/java/com/nothinglauncher/NothingLockAccessibilityService.kt) (`GLOBAL_ACTION_LOCK_SCREEN`).
- **Long-press Shortcuts ([`NothingShortcuts`](../app/src/main/java/com/nothinglauncher/home/NothingShortcuts.kt)):** Appends *Hide in Vault* and *Rename* (`ITEM_TYPE_APPLICATION`) to Launcher3's popup shortcut menu.
- **Essential Space ([`EssentialSpaceOverlay`](../app/src/main/java/com/nothinglauncher/space/EssentialSpaceOverlay.kt)):** Mounts lazily inside `dragLayer`, tracks finger velocity and fling thresholds for 1:1 drawer-like reveal from page 0, and unifies Daily Briefing, Hardware Switchboard, Scratchpad Note, Voice Memos, Focus Timer/Stopwatch, and Device Vitals.

## 3. Preferences, Repositories & Backup

- [`NothingPrefs`](../app/src/main/java/com/nothinglauncher/NothingPrefs.kt) stores all Not a Thing configuration, notes, timer timestamps, habit dates, hidden package sets, custom app labels, recent component history, quick folder bindings, and per-widget surface overrides, with a `ConcurrentHashMap` fallback for headless JVM/Robolectric tests. Launcher3's grid, auto-rotation, and themed-icon flags continue to go straight through `LauncherPrefs` / `InvariantDeviceProfile`.
- [`SetupBackupManager`](../app/src/main/java/com/nothinglauncher/SetupBackupManager.kt) serializes/deserializes `.nothing.json` workspace setups via Android Storage Access Framework (`ACTION_CREATE_DOCUMENT` / `ACTION_OPEN_DOCUMENT`) and provides 4 one-tap presets (`TELEMETRY`, `MONOLITH`, `COMMAND`, `STUDIO`).
- Shared zero-idle repositories coordinate state across Essential Space and home widgets without foreground/background services: [`WeatherRepository`](../app/src/main/java/com/nothinglauncher/WeatherRepository.kt), [`MediaSessionRepository`](../app/src/main/java/com/nothinglauncher/MediaSessionRepository.kt) (with background Bayer 4×4 quantization), [`HardwareControlRepository`](../app/src/main/java/com/nothinglauncher/HardwareControlRepository.kt), [`FocusTimerRepository`](../app/src/main/java/com/nothinglauncher/FocusTimerRepository.kt), and [`VoiceMemoRepository`](../app/src/main/java/com/nothinglauncher/VoiceMemoRepository.kt).

## 4. Dot-Matrix Widgets (11 Elements)

All 11 widgets extend [`NothingWidget`](../app/src/main/java/com/nothinglauncher/widgets/NothingWidget.kt) under `app/src/main/java/com/nothinglauncher/widgets/` and are registered in append-only order in `R.array.custom_widget_providers` ([`nt_config.xml`](../app/src/main/res/values/nt_config.xml)):

| # | Class | Behaviour |
|---|---|---|
| 0 | `ClockWidget` | Digital (12/24h + seconds), `AnalogDotClockView`, `WordClockFormatter`, and World Clock (`worldClockZoneId`) |
| 1 | `BatteryCalendarWidget` | Battery dot arc + animated charging bolt, Calendar date link, and auto-hidden empty alarm row |
| 2 | `WeatherWidget` | Open-Meteo conditions with compact (`2×2`) vs wide (`4×2+`) 12h temperature sparkline & wind speed |
| 3 | `MediaWidget` | Live track/artist, transport controls, audio output route (`BT`/`WIRED`/`SPEAKER`), and `MediaArtHalftone` |
| 4 | `QuickTogglesWidget` | Direct tiles for Torch, Focus Mode, Caffeine, and Ringer cycle |
| 5 | `FocusTimerWidget` | `DotRingGaugeView` Pomodoro timer & stopwatch synced with Essential Space |
| 6 | `EssentialNoteWidget` | Always-visible scratchpad synced with Essential Space |
| 7 | `HabitMatrixWidget` | 7×7 historical habit streak grid (`HabitPegboardView`) with 1-tap check-in and custom title |
| 8 | `VitalsWidget` | Storage + live RAM dot bars and optional daily `UsageStatsManager` screen time |
| 9 | `CompassStepWidget` | Hardware azimuth dot compass + step counter strictly gated on `onVisibilityAggregated` |
| 10 | `SmartFolderWidget` | Interactive 2×2 quick-launch stack with custom header |

[`DateTimeWidgetProvider`](../app/src/main/java/com/nothinglauncher/widgets/DateTimeWidgetProvider.kt) remains registered as a lightweight `AppWidgetProvider` so Launcher3's `CustomWidgetManager` always finds at least one system widget provider and binds the in-process elements above.

## 5. Offline Command Search, Smart Drawer & Hidden Vault

- [`CommandEngine`](../app/src/main/java/com/nothinglauncher/search/CommandEngine.kt) evaluates recursive-descent math + `%`, unit & temperature conversions, city timezone lookups, device quick actions, optional `READ_CONTACTS` filtering, web search, and acronym/initials + 1-typo fuzzy app matching (`scoreApp`).
- [`NothingAllAppsContainerView`](../app/src/main/java/com/nothinglauncher/drawer/NothingAllAppsContainerView.kt) toggles Grid ↔ Minimal List layout seamlessly, injects Command Cards via `AllAppsGridAdapter`, filters `NothingPrefs.hiddenPackages`, and exposes recent-app pills (`DrawerHeader`) plus the biometric/device-credential [`HiddenVaultSheet`](../app/src/main/java/com/nothinglauncher/drawer/HiddenVaultSheet.kt).

## 6. Visual Tiers, Tactile Physics, Icons & Accents

- [`VisualTier`](../app/src/main/java/com/nothinglauncher/perf/VisualTier.kt) classifies devices into `LITE` / `BALANCED` / `RICH` (with automatic `ApplicationExitInfo` downgrade to `LITE` after low-memory kills and cache eviction in `NothingApplication.onTrimMemory` / picker dismissal in `NothingLauncher.onTrimMemory`), honoring Battery Saver and disabled animations.
- [`Tactile`](../app/src/main/java/com/nothinglauncher/Tactile.kt) drives press-scale and spring rebound via AndroidX `SpringAnimation`, haptic ticks/confirmations, and optional 4 ms synthesized mechanical click audio in [`TactileAudio`](../app/src/main/java/com/nothinglauncher/TactileAudio.kt).
- [`NothingIconLogic`](../app/src/main/java/com/nothinglauncher/icons/NothingIconLogic.kt), [`IconFactory`](../app/src/main/java/com/nothinglauncher/IconFactory.kt), [`IconPackManager`](../app/src/main/java/com/nothinglauncher/icons/IconPackManager.kt), and [`AccentTheme`](../app/src/main/java/com/nothinglauncher/AccentTheme.kt) provide Monochrome, Original Colour, 13×13 Dot-Matrix Glyph icons, ADW/Nova third-party icon packs, per-app custom labels, and 5 hardware accent palettes (`RED`, `AMBER`, `PHOSPHOR`, `COBALT`, `MONO`).

## 7. Build Pipeline & R8 Reflection Contract

```
third_party/aosp/launcher3/   <- vendored, unmodified AOSP sources
         |
         v
   :launcher3, :iconloader, :animationlib   <- compiles AOSP sources + config & src_ui_overrides
         |
         v
       :app   <- com.nothinglauncher: v13 UI, widgets, overlay, search, vault, settings, generated theme
```

Classes resolved by name or private field reflection must survive release R8 minification:
- All 11 `NothingWidget` subclasses in `R.array.custom_widget_providers` keep public `(Context)` constructors via `app/proguard-rules.pro` and `launcher3/consumer-rules.pro`.
- `NothingIconLogic` is preserved via AOSP `ResourceBasedOverride` rules.
- `AppsSearchContainerLayout.mSearchBarController` is explicitly kept in `app/proguard-rules.pro` so `DrawerSearchBox` binds `NothingSearchAlgorithm` in minified release APKs.
- `tools/verify_release_reflection.py` runs after `assembleRelease` (when Python 3 is present) to verify reflective entries against `app-release.apk`.
